# Reglas de Negocio

## Seguridad

RN-001

Todo usuario deberá autenticarse para acceder al sistema.

RN-002

Un usuario puede tener uno o varios roles.

RN-003

Los permisos serán administrados mediante roles.

---

## Inventario

RN-004

Todo producto pertenece a una categoría.

RN-005

Todo movimiento debe tener un responsable.

RN-006

No podrá existir stock negativo.

RN-007

Todo movimiento generará historial.

RN-008

El stock será calculado.

Nunca modificado manualmente.

RN-009

Todo producto tendrá una unidad de medida.

RN-010

Los activos deberán poseer un número de serie único.
